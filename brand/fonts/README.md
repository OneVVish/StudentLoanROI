# Bundled display faces

**Inter Display**, by The Inter Project Authors, under the SIL Open Font
License 1.1 (`Inter-OFL-LICENSE.txt`). Version 4.1, downloaded 2026-09-12 from
`github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip`.

**Why it is bundled rather than installed.** `brand/README.md` records that the
wordmark is set in Avenir Next, "which is licensed, not open", and that
"converting outlines does not convert the licence". A book cover sold for money
is the sharpest form of that question, so the cover's display type is re-cut in
an OFL face instead. Bundling it means the cover reproduces on a clone and on
CI rather than depending on what happens to be installed on one Mac.

Only the three weights the cover uses are here. Inter Display is the optical
size drawn for large type; plain Inter is drawn for text and is not what a
cover wants.

The OFL permits redistribution with the licence file, which is why
`Inter-OFL-LICENSE.txt` sits beside the faces and must stay there.
